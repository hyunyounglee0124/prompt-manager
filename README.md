# 🚀 나만의 AI 프롬프트 관리 시스템 v2.0 (Prompt Manager)

파편화된 GenAI 프롬프트(텍스트 생성, 이미지 생성, 영상 스크립트, 페르소나 설계 등)를 파이썬 콘솔 환경에서 체계적으로 저장, 관리, 검색 및 내보낼 수 있는 소프트웨어 프로젝트입니다.

---

## 📌 주요 특징 및 기능

1. **기본 프롬프트 제공**: 패션 스타일링, 블로그 매니저, ADER ERROR 광고 스크립트 등 3종 기본 내장
2. **자동 JSON 영속화 (`prompts.json`)**: 프로그램 실행 중 데이터 추가, 수정, 삭제, 즐겨찾기 변경 시 자동으로 파일에 저장되어 종료 후에도 데이터 유지
3. **카테고리 필터링 & 키워드 검색**: 카테고리별 분리 조회 및 대소문자 구문 없는 키워드 검색 기능
4. **상세보기 & 인기도 시스템**: 프롬프트 본문 글자 수/줄 수 카운트, 등록일시 표시 및 조회수 기준 TOP 목록 제공
5. **CRUD 풀 관리**: 기존 프롬프트에 대한 수정 및 삭제 기능 제공
6. **Markdown 자동 내보내기**: 카테고리별 구조화 문서(`exported_prompts.md`)로 즉시 내보내기
