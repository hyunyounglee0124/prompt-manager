# 🚀 나만의 AI 프롬프트 관리 시스템 (Prompt Manager)

> 파편화된 GenAI 프롬프트(텍스트 생성, 이미지 생성, 영상 스크립트, 페르소나 설계 등)를
> 파이썬 **콘솔 환경**에서 저장 · 분류 · 검색 · 즐겨찾기 · 내보내기까지 관리하는 CLI 프로그램입니다.

메모장, 노션, 메신저에 흩어져 있던 프롬프트를 한 곳에 모아 **"그때 그 프롬프트"를 3초 안에 찾는 것**을 목표로 만들었습니다.
외부 라이브러리 없이 **파이썬 기본 문법(리스트 · 딕셔너리 · 함수 · 반복문 · 조건문)** 만으로 구현했습니다.

## 💡 프로젝트 소개

### 왜 만들었나요?

| 기존 방식의 불편함 | 이 프로그램이 해결하는 방법 |
| --- | --- |
| 프롬프트가 메모장 · 노션 · 메신저에 흩어져 있음 | 한 프로그램에서 **추가 · 조회 · 검색**으로 통합 관리 |
| 카테고리 구분 없이 뒤섞여 있어 찾기 어려움 | 6개 카테고리로 분류 + **카테고리별 조회** |
| 매번 복사 · 붙여넣기 하느라 생성 흐름이 끊김 | **즐겨찾기(⭐)** 로 자주 쓰는 프롬프트를 상단에서 즉시 확인 |
| 프로그램을 끄면 입력한 내용이 사라짐 | `prompts.json`에 **자동 저장**되어 다음 실행 때 그대로 복원 |
| 프롬프트를 다른 사람에게 공유하기 어려움 | **Markdown 내보내기**로 문서 형태로 즉시 공유 |

### 이 프로젝트의 목표

1. 프롬프트를 **리스트 + 딕셔너리** 자료구조로 다루며 데이터 관리 논리를 익힌다.
2. `add_prompt()`, `show_list()`, `search_prompt()`처럼 **기능별로 함수를 분리**해 코드를 구조화한다.
3. 사용자의 잘못된 입력(빈 값, 범위를 벗어난 번호)을 **안내 메시지와 함께 재입력**하도록 처리한다.
4. Git으로 기능 단위 커밋 · 브랜치 생성 · 병합을 수행하고 GitHub에 공개한다.

## ⚙️ 주요 기능

| 번호 | 메뉴 | 기능 설명 | 관련 함수 |
| :---: | --- | --- | --- |
| 1 | ➕ 프롬프트 추가 | 제목 · 내용 · 카테고리를 입력받아 새 프롬프트를 등록합니다. 빈 값은 재입력을 요청합니다. | `add_prompt()` |
| 2 | 📋 전체 프롬프트 목록 보기 | 저장된 모든 프롬프트를 번호 · 즐겨찾기(⭐) · 카테고리 · 제목 · 조회수와 함께 출력합니다. | `show_list()` |
| 3 | 📁 카테고리별 조회 | 카테고리를 골라 해당 카테고리의 프롬프트만 모아서 봅니다. | `view_by_category()` |
| 4 | 🔍 키워드 검색 | **제목 또는 내용**에 키워드가 포함된 프롬프트를 찾습니다. (대소문자 구분 없음) | `search_prompt()` |
| 5 | 📖 프롬프트 상세 보기 | 프롬프트의 전체 내용, 등록일시, 글자 수 / 줄 수를 확인합니다. **조회 시 조회수 +1** 증가합니다. | `show_detail()` |
| 6 | ⭐ 즐겨찾기 설정/해제 | 번호를 입력해 즐겨찾기를 **토글** 방식으로 켜고 끕니다. | `toggle_favorite()` |
| 7 | 🌟 즐겨찾기 모아보기 | 즐겨찾기된 프롬프트만 따로 모아 출력합니다. | `show_favorites()` |
| 8 | 🔥 인기 프롬프트 TOP | **조회수 기준 내림차순**으로 정렬해 보여줍니다. | `show_top_views()` |
| 9 | 🛠️ 프롬프트 수정 / 삭제 | 기존 프롬프트의 제목 · 내용을 수정하거나, 확인 절차(`y/N`) 후 삭제합니다. | `manage_prompt()` |
| 10 | 📄 Markdown 파일 내보내기 | 전체 프롬프트를 카테고리별로 정리한 `exported_prompts.md`를 생성합니다. | `export_to_markdown()` |
| 0 | 🚪 종료 | 데이터를 저장하고 프로그램을 안전하게 종료합니다. | `main()` |
| — | ❌ 잘못된 입력 | 안내 메시지를 출력하고 **다시 메뉴로 돌아옵니다.** | `main()` |

### 보너스 과제 구현 현황

## ▶️ 실행 방법

### 1. 요구 사항

- **Python 3.10 이상** (별도 라이브러리 설치 불필요)
- 터미널(명령 프롬프트 / PowerShell / VSCode 통합 터미널)

```bash
# 설치 확인
python3 --version        # macOS · Linux
python --version         # Windows
```

### 2. 저장소 내려받기

```bash
git clone <본인 GitHub 저장소 URL>
cd prompt-manager
```

### 3. 실행

```bash
python3 main.py     # macOS · Linux
python main.py      # Windows
```

### 4. 첫 실행 시 자동으로 만들어지는 파일

| 파일 | 생성 시점 | 설명 |
| --- | --- | --- |
| `prompts.json` | 파일이 없을 때 최초 실행 | 기본 프롬프트 3종이 자동 저장됩니다. |
| `exported_prompts.md` | 메뉴 **10번** 실행 시 | 내보내기 할 때마다 최신 내용으로 덮어씁니다. |

> 💡 두 파일 모두 `main.py`와 **같은 폴더**에 생성됩니다. 다른 폴더에서 실행하면 그 폴더에 만들어지니, 실행 위치를 확인하세요.

### 5. 종료 방법

메뉴에서 `0`을 입력합니다. (Ctrl+C로 강제 종료해도 이미 저장된 데이터는 유지됩니다.)

### 1️⃣ 프롬프트 추가

제목 → 내용 → 카테고리 순서로 입력합니다. 각 항목이 **비어 있으면 다시 입력을 요청**합니다.

```text
[ ➕ 새 프롬프트 추가 ]
📌 제목 입력: 인스타그램 카드뉴스 생성기
📝 프롬프트 내용 입력: 당신은 SNS 콘텐츠 전문가입니다. 주제를 입력하면 8장짜리 카드뉴스 기획안을 만들어주세요.
🏷️ 카테고리 선택:
  1. 텍스트 생성
  2. 이미지 생성
  3. 영상 생성
  4. 페르소나
  5. 자동화
  6. 기타
👉 번호 선택 (또는 직접 입력):

✅ '인스타그램 카드뉴스 생성기' 프롬프트가 성공적으로 추가되었습니다! (카테고리: 기타)
```

**카테고리 입력 규칙**

| 입력값 | 처리 결과 |
| --- | --- |
| `1` ~ `6` | 해당 번호의 기본 카테고리로 등록 |
| `마케팅` 처럼 직접 입력 | 입력한 문자열이 그대로 카테고리로 등록 |
| 그냥 엔터(빈 값) | **기타** 로 자동 등록 |

추가된 프롬프트의 즐겨찾기 기본값은 `False`, 조회수는 `0`이며, 등록 시각이 자동 기록됩니다.

### 2️⃣ 전체 프롬프트 목록 보기

```text
[ 📋 전체 프롬프트 목록 ]
----------------------------------------------------
 1. ⭐ [페르소나]     얼굴 외형과 체형에 따른 옷 디자인 및 브랜드 매칭 (조회수: 0)
 2.    [텍스트 생성]   남성 패션 블로그 프롬프트 매니저 (조회수: 0)
 3. ⭐ [영상 생성]    ADER ERROR 브랜드 광고 영상 스크립트 (조회수: 0)
----------------------------------------------------
총 3개의 프롬프트
```

- ⭐ 표시가 있는 항목이 즐겨찾기된 프롬프트입니다.
- 프롬프트가 하나도 없으면 `등록된 프롬프트가 없습니다.` 를 출력합니다.

### 3️⃣ 카테고리별 조회

카테고리 목록에서 번호를 선택하면 해당 카테고리만 필터링해서 보여줍니다.

```text
[ 📁 카테고리별 조회 ]
  1. 텍스트 생성
  2. 이미지 생성
  3. 영상 생성
  4. 페르소나
  5. 자동화
  6. 기타
👉 조회할 카테고리 번호: 4

[ 📋 '페르소나' 카테고리 목록 ]
----------------------------------------------------
 1. ⭐ [페르소나]     얼굴 외형과 체형에 따른 옷 디자인 및 브랜드 매칭 (조회수: 0)
----------------------------------------------------
총 1개의 프롬프트
```

해당 카테고리에 프롬프트가 없으면 `등록된 프롬프트가 없습니다.` 안내가 출력됩니다.

---

### 4️⃣ 키워드 검색

제목과 내용을 **모두 대상으로** 대소문자 구분 없이 검색합니다.

```text
[ 🔍 키워드 검색 ]
👉 검색어 입력 (제목 또는 내용): 패션

[ 📋 '패션' 검색 결과 ]
----------------------------------------------------
 1. ⭐ [페르소나]     얼굴 외형과 체형에 따른 옷 디자인 및 브랜드 매칭 (조회수: 1)
 2.    [텍스트 생성]   남성 패션 블로그 프롬프트 매니저 (조회수: 0)
----------------------------------------------------
총 2개의 프롬프트
```

검색 결과가 없으면 `등록된 프롬프트가 없습니다.` 안내가 출력되고, 검색어를 입력하지 않으면 `❌ 검색어를 입력해주세요.` 메시지와 함께 메뉴로 돌아옵니다.

---

### 5️⃣ 프롬프트 상세 보기

목록에서 번호를 입력하면 본문 전체와 메타 정보를 확인할 수 있습니다.
이때 **조회수가 1 증가**하고 즉시 파일에 저장됩니다.

```text
👉 상세 조회할 프롬프트 번호 입력: 1

════════════════════════════════════════════════════
📌 제목     : 얼굴 외형과 체형에 따른 옷 디자인 및 브랜드 매칭
🏷️ 카테고리 : 페르소나
⭐ 즐겨찾기 : ⭐ (등록됨)
👁️ 조회수   : 1 회
📅 등록일시 : 2026-09-28 10:00:00
📊 글자수   : 약 131자 (1줄)
────────────────────────────────────────────────────
📝 프롬프트 본문:
사용자의 얼굴형(달걀형, 각진형, 라운드형 등)과 체형(체격, 키, 어깨 너비) 데이터를 분석하여
최적의 패션 스타일링 및 옷 디자인을 추천하고, 이에 어울리는 브랜드(컨템포러리, 캐주얼, 스트릿 등)를
매칭해주는 AI 프롬프트입니다.
════════════════════════════════════════════════════
```

목록에 없는 번호를 입력하면 `❌ 올바른 번호가 아닙니다.` 를 출력합니다.

---

### 6️⃣ 즐겨찾기 설정 / 해제 (토글)

같은 번호를 다시 누르면 해제됩니다. 별도의 "해제" 메뉴가 필요 없습니다.

```text
👉 즐겨찾기 설정/해제할 번호 입력: 2

✅ '남성 패션 블로그 프롬프트 매니저' 프롬프트가 ⭐ 즐겨찾기에 추가 되었습니다.
```

한 번 더 실행하면 `❌ 즐겨찾기에서 해제 되었습니다.` 가 출력됩니다.

### 7️⃣ 즐겨찾기 모아보기

```text
[ 📋 ⭐ 즐겨찾기 프롬프트 목록 ]
----------------------------------------------------
 1. ⭐ [페르소나]     얼굴 외형과 체형에 따른 옷 디자인 및 브랜드 매칭 (조회수: 1)
 2. ⭐ [영상 생성]    ADER ERROR 브랜드 광고 영상 스크립트 (조회수: 0)
----------------------------------------------------
총 2개의 프롬프트
```

즐겨찾기한 프롬프트가 없으면 `등록된 프롬프트가 없습니다.` 를 출력합니다.

---

### 8️⃣ 인기 프롬프트 TOP (조회수 순)

상세 보기로 많이 열어본 프롬프트가 위로 올라옵니다. "내가 실제로 자주 쓰는 프롬프트"를 파악할 수 있습니다.

```text
[ 📋 🔥 인기 프롬프트 (조회수 순) ]
----------------------------------------------------
 1.    [텍스트 생성]   남성 패션 블로그 프롬프트 매니저 (조회수: 7)
 2. ⭐ [페르소나]     얼굴 외형과 체형에 따른 옷 디자인 및 브랜드 매칭 (조회수: 3)
 3. ⭐ [영상 생성]    ADER ERROR 브랜드 광고 영상 스크립트 (조회수: 0)
----------------------------------------------------
총 3개의 프롬프트
```

### 9️⃣ 프롬프트 수정 / 삭제

```text
1) 프롬프트 수정  |  2) 프롬프트 삭제
👉 작업 선택: 1
👉 대상 프롬프트 번호 입력: 2

[ 수정 대상: 남성 패션 블로그 프롬프트 매니저 ]
새 제목 (엔터 시 유지: 남성 패션 블로그 프롬프트 매니저):
새 내용 (엔터 시 유지):
✅ 성공적으로 수정되었습니다.
```

- **입력하지 않고 엔터만 누르면 기존 값이 유지**되므로, 바꾸고 싶은 항목만 입력하면 됩니다.
- 삭제는 실수를 막기 위해 한 번 더 확인합니다.

```text
⚠️ 정말 '남성 패션 블로그 프롬프트 매니저' 프롬프트를 삭제하시겠습니까? (y/N): y
🗑️ '남성 패션 블로그 프롬프트 매니저' 프롬프트가 삭제되었습니다.
```

`y` 이외의 값을 입력하면 `삭제가 취소되었습니다.` 가 출력되며 데이터는 그대로 유지됩니다.

## 🗂️ 데이터 구조

### 자료구조 설계

프롬프트 하나는 **딕셔너리(dict)**, 전체 프롬프트는 그 딕셔너리들을 담은 **리스트(list)** 로 관리합니다.

```text
prompts = [ {프롬프트1}, {프롬프트2}, {프롬프트3}, ... ]
              ↑ dict        ↑ dict       ↑ dict
```

```python
prompts = [
    {
        "id": 1,
        "title": "얼굴 외형과 체형에 따른 옷 디자인 및 브랜드 매칭",
        "content": "사용자의 얼굴형(달걀형, 각진형, 라운드형 등)과 체형(체격, 키, 어깨 너비) 데이터를 분석하여 ...",
        "category": "페르소나",
        "favorite": True,
        "views": 0,
        "created_at": "2026-09-28 10:00:00"
    },
    {
        "id": 2,
        "title": "남성 패션 블로그 프롬프트 매니저",
        "content": "당신은 10년 경력의 남성 전문 패션 블로거입니다. ...",
        "category": "텍스트 생성",
        "favorite": False,
        "views": 0,
        "created_at": "2026-09-28 11:30:00"
    }
]
```

### 필드 정의

| 키(key) | 타입 | 설명 | 예시 |
| --- | :---: | --- | --- |
| `id` | int | 프롬프트 고유 번호. 추가 시 `get_next_id()`가 자동 부여 (기존 최대값 + 1) | `1` |
| `title` | str | 프롬프트 제목 (필수 · 공백 불가) | `"남성 패션 블로그 프롬프트 매니저"` |
| `content` | str | 프롬프트 본문 (필수 · 공백 불가) | `"당신은 10년 경력의 ..."` |
| `category` | str | 카테고리명 (기본 6종 또는 직접 입력값) | `"텍스트 생성"` |
| `favorite` | bool | 즐겨찾기 여부. 추가 시 기본값 `False` | `True` |
| `views` | int | 상세 보기를 실행한 횟수(조회수) | `3` |
| `created_at` | str | 등록 일시 (`YYYY-MM-DD HH:MM:SS`) | `"2026-09-28 10:00:00"` |

### 파일 저장 형식 (`prompts.json`)

`json.dump(prompts, f, ensure_ascii=False, indent=4)` 로 저장하므로, **한글이 깨지지 않고** 사람이 읽기 좋은 형태로 저장됩니다.

```json
[
    {
        "id": 1,
        "title": "얼굴 외형과 체형에 따른 옷 디자인 및 브랜드 매칭",
        "content": "사용자의 얼굴형(달걀형, 각진형, 라운드형 등)과 체형(체격, 키, 어깨 너비) 데이터를 분석하여 ...",
        "category": "페르소나",
        "favorite": true,
        "views": 1,
        "created_at": "2026-09-28 10:00:00"
    }
]
```

**저장 시점** — 데이터가 바뀌는 모든 순간에 자동으로 저장됩니다.

| 동작 | 저장 여부 | 비고 |
| --- | :---: | --- |
| 프로그램 시작 | ✅ | `prompts.json`이 없으면 기본 데이터로 새로 생성 |
| 프롬프트 추가 | ✅ | |
| 즐겨찾기 토글 | ✅ | |
| 상세 보기 (조회수 증가) | ✅ | |
| 프롬프트 수정 / 삭제 | ✅ | |
| 프로그램 종료 (`0` 입력) | ✅ | 이중 안전장치 |

## 🧩 함수 구조

모든 코드를 한 함수에 몰아넣지 않고, **기능별로 16개 함수**로 분리했습니다.

| 구분 | 함수 | 역할 |
| --- | --- | --- |
| 데이터 | `load_data()` | `prompts.json`을 읽어 전역 `prompts`에 적재. 파일이 없거나 손상되면 기본 데이터 사용 |
| 데이터 | `save_data(silent=False)` | 현재 데이터를 JSON으로 저장. `silent=True`면 성공 메시지 생략 |
| 데이터 | `get_next_id()` | 기존 프롬프트의 최대 `id` + 1 을 반환 |
| 화면 | `show_menu()` | 메인 메뉴(1~10, 0) 출력 |
| 화면 | `format_prompt_row(idx, item)` | 목록 한 줄 서식(번호 · ⭐ · 카테고리 · 제목 · 조회수) 생성 |
| 화면 | `show_list(target_list=None, header=...)` | 프롬프트 목록 출력. **전체/필터/검색 결과를 모두 이 함수로 재사용** |
| 기능 | `add_prompt()` | 새 프롬프트 입력 · 검증 · 등록 |
| 기능 | `view_by_category()` | 카테고리 선택 후 해당 카테고리만 필터링 |
| 기능 | `search_prompt()` | 제목 · 내용 키워드 검색 |
| 기능 | `show_detail()` | 상세 조회 + 조회수 증가 + 글자 수/줄 수 계산 |
| 기능 | `toggle_favorite()` | 즐겨찾기 추가 · 해제 |
| 기능 | `show_favorites()` | 즐겨찾기 목록만 출력 |
| 기능 | `show_top_views()` | 조회수 내림차순 정렬 후 출력 |
| 기능 | `manage_prompt()` | 수정 / 삭제(확인 절차 포함) |
| 기능 | `export_to_markdown()` | 카테고리별 Markdown 문서 생성 |
| 실행 | `main()` | 프로그램 시작 · 메뉴 루프 · 입력 분기 · 종료 |

### 전체 실행 흐름

```text
프로그램 시작
   │
   ├─ load_data()  ── prompts.json 있음 → 저장된 데이터 불러오기
   │                 prompts.json 없음 → DEFAULT_PROMPTS 3종으로 시작 + 파일 생성
   │
   └─ while True (무한 반복)
        │
        ├─ show_menu()            메뉴 출력
        ├─ input()                번호 입력
        │
        ├─ "1"  → add_prompt()
        ├─ "2"  → show_list()
        ├─ "3"  → view_by_category()
        ├─ "4"  → search_prompt()
        ├─ "5"  → show_detail()          → 조회수 +1 → save_data()
        ├─ "6"  → toggle_favorite()      → save_data()
        ├─ "7"  → show_favorites()
        ├─ "8"  → show_top_views()
        ├─ "9"  → manage_prompt()        → save_data()
        ├─ "10" → export_to_markdown()
        ├─ "0"  → save_data() → 종료 메시지 → break
        └─ 그 외 → "잘못된 입력" 안내 후 메뉴로 복귀
```

## 🌿 Git 워크플로우

### 저장소 초기화와 첫 업로드

```bash
# 1) GitHub에서 새 저장소 생성 후, 로컬에서 저장소 시작
git init

# 2) 원격 저장소 연결
git remote add origin https://github.com/<본인계정>/prompt-manager.git

# 3) 파일 스테이징 및 첫 커밋
git add .
git commit -m "chore: 프로젝트 초기 설정 및 README 추가"

# 4) 원격 저장소로 업로드 (최초 1회는 -u로 추적 설정)
git push -u origin main
```

### 기능 단위 커밋 규칙

커밋 메시지는 **접두어: 변경 의도** 형식으로 작성해, 한눈에 어떤 작업이었는지 알 수 있게 했습니다.

| 접두어 | 의미 | 예시 |
| --- | --- | --- |
| `feat` | 새 기능 추가 | `feat: 프롬프트 추가 기능 구현` |
| `fix` | 버그 수정 | `fix: 잘못된 번호 입력 시 예외 처리 보완` |
| `refactor` | 코드 구조 개선 | `refactor: 목록 출력 로직을 show_list()로 통합` |
| `docs` | 문서 작성 · 수정 | `docs: README에 실행 방법 추가` |
| `chore` | 설정 · 정리 | `chore: .gitignore 추가` |

### 브랜치 생성 및 병합

`프롬프트 목록` 기능은 별도 브랜치에서 작업한 뒤 `main`에 병합했습니다.

```bash
# 1) 기능 브랜치 생성 및 이동
git checkout -b feature/prompt-list

# 2) 작업 후 커밋
git add main.py
git commit -m "feat: 프롬프트 목록 출력 기능 구현"

# 3) main 브랜치로 복귀
git checkout main

# 4) 브랜치 병합
git merge feature/prompt-list

# 5) 병합 결과를 원격 저장소에 반영
git push origin main
```

### 사용한 Git 명령 요약

| 명령 | 사용 목적 |
| --- | --- |
| `git init` | 프로젝트 폴더를 Git 저장소로 초기화 |
| `git add` | 변경 파일을 커밋 대상(스테이지)에 등록 |
| `git commit` | 변경 이력을 기능 단위로 기록 |
| `git push` | 로컬 커밋을 GitHub 원격 저장소에 업로드 |
| `git pull` | 원격 저장소의 최신 변경 사항을 로컬로 내려받아 병합 |
| `git checkout` | 브랜치 생성 및 이동 (`-b` 옵션 사용) |
| `git clone` | 공개 샘플 저장소를 내려받아 구조와 로그 확인 후 삭제 |
| `git merge` | 기능 브랜치를 `main` 브랜치에 병합 |

## 🔎 알려진 동작과 개선 아이디어

현재 동작을 정확히 이해하고 사용하기 위한 참고 사항입니다.

| 항목 | 내용 |
| --- | --- |
| **번호 기준** | 목록 · 상세 보기 · 즐겨찾기 · 수정/삭제의 번호는 **항상 전체 목록 기준**입니다. 검색·카테고리 조회 결과의 번호는 화면 표시용이므로, 상세 보기를 할 때는 전체 목록(메뉴 2번)에서 번호를 확인하세요. |
| **데이터 영속성** | 기본 요구사항은 "실행 중에만 유지"지만, 보너스 1을 적용해 `prompts.json`에 저장하므로 **프로그램을 종료해도 데이터가 유지**됩니다. |
| **카테고리 변경** | 수정 기능은 제목 · 내용만 변경합니다. 카테고리를 바꾸려면 삭제 후 다시 추가하세요. |
| **1줄 입력** | 내용을 한 줄로 입력하도록 되어 있습니다. 여러 줄 프롬프트가 필요하면 `'''` 블록 입력 방식으로 확장할 수 있습니다. |
| **다중 사용자** | 단일 사용자 · 로컬 파일 기반이므로 동시 실행은 지원하지 않습니다. |

**다음 단계 아이디어**

- 검색 결과에서도 바로 상세 보기로 이동하도록 `id` 기반 선택으로 개선
- 카테고리별 조회에도 수정 · 삭제 기능 연결
- 검색어 여러 개(AND/OR) 지원 및 즐겨찾기 우선 정렬 옵션
- CSV / Markdown 추가 포맷 내보내기 및 가져오기(Import)

## 🧯 트러블슈팅

| 증상 | 원인 | 해결 방법 |
| --- | --- | --- |
| `python: command not found` | Python 미설치 또는 PATH 미등록 | Python 3.10 이상 설치 후 터미널 재시작, `python3 --version` 으로 확인 |
| 실행했는데 목록이 비어 있음 | `prompts.json`이 존재하고 빈 배열(`[]`)인 경우 | 해당 파일을 삭제하고 다시 실행하면 기본 프롬프트 3종이 복원됩니다. |
| 저장된 내용이 다음 실행 때 안 보임 | 실행 폴더가 달라 `prompts.json`이 다른 위치에 생성됨 | `main.py`가 있는 폴더에서 실행 (`cd` 로 이동 후 실행) |
| 한글이 깨져 보임 | 터미널 인코딩 문제 | Windows: `chcp 65001` 실행 / 파일은 모두 UTF-8로 저장 |
| `⚠️ [경고] 데이터 로드 중 오류 발생` | `prompts.json` 형식이 손상됨 | 파일을 열어 JSON 형식(대괄호 · 쉼표 · 큰따옴표)을 확인하거나 삭제 후 재실행 |
| GitHub에 푸시가 거부됨 | 원격에 로컬에 없는 커밋이 존재 | `git pull origin main` 으로 병합 후 다시 `git push` |
